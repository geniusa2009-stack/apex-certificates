The signing key lives in a cloud KMS/HSM and never leaves it. Public keys are published at verify.apex.org/.well-known/apex-keys.json with key IDs, so old certificates remain verifiable after rotation. Sample records on the verification page are signed with a throwaway Ed25519 test key (env “sample”), which production verification rejects.
